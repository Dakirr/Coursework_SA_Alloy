# Программная реализация модели модифицированной задачи Эйнштейна

Программная реализация состоит из двух модулей: генератора кода на Python и собственно решающей модели на языке Alloy.

## Python

1. Main.py - содержит пример, демонстрирующий возможности генератора.
2. AlloyBuilder.py - генератор кода для Alloy. Обладает интерфейсом для генерации кода на языке Alloy для дальнейшей проверки совместности.
3. IslandModellingLogsParcer.py - модуль, создающий AlloyBuilder на основе логов симуляции сервера из _src/_.

**Файлы из папки src/ не генерируются модулем, их формат и наполнение взяты из сторонней реализации симуляции острова, доступной по ссылке** https://github.com/cathlx/zebra_puzzle_island.


## Alloy

Модуль запускает созданные файлы модели с целью проверить совместность модели с помощью собранного модуля **Alloy** (https://github.com/AlloyTools/org.alloytools.alloy).


## Запуск

Программа запускается из корневой директории с помощью `docker-compose up`.
